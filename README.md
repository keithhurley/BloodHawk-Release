# BloodHawk 🦅🩸
### Advanced Tactical Blood Tracking & Optical Game Recovery

**BloodHawk** is an advanced field application built for hunters, trackers, and outdoor retrieval specialists. BloodHawk leverages high-speed native computer vision (OpenCV / NDK C++17), multi-spectral blood chemistry envelope classification, dynamic background color-space repulsion, real-time GPS trail mapping with offline topological cache, and audio geiger feedback.

---

## 📥 Download & Installation

1. Navigate to the **[Latest Release](../../releases/latest)**.
2. Download the BloodHawk-vX.X.X.apk asset.
3. Open the downloaded APK on your Android device (ensure "Install from Unknown Sources" or browser permissions are allowed).
4. Launch **BloodHawk**!

---

## 🔄 In-App Updates

BloodHawk features an integrated **Check for Updates** engine directly inside the app:
- Tap **Settings & Diagnostics** from the home HUD.
- Under **Application Updates**, tap **🔄 Check for Updates**.
- BloodHawk automatically queries this public release repository, compares your current installed version, and prompts you to download and install updates in one tap!

---

## ⚙️ Requirements
- **OS**: Android 8.0 (Oreo / API 26) or higher (compatible up to Android 15/16 with 16KB page alignment)
- **Architecture**: arm64-v8a, armeabi-v7a
- **Hardware**: Camera with flash/torch, GPS location sensor, OpenGL ES 3.0+
